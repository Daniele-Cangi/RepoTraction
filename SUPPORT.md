# RepoTraction Support

RepoTraction is an open-source, local-first GitHub analytics application.

## Getting help

For support, private bug reports, or project questions, contact:

**daniele.tl.project@gmail.com**

For non-sensitive bugs and feature requests, please use the repository's GitHub Issues.

When reporting a problem, include the RepoTraction version, operating system, Python version, and the relevant error message. Do not include GitHub access tokens, credentials, or exported private repository data.
