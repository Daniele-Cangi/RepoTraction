# Luna explicit scope results and abstention limits

The reviewed nine-case experiment completed with **nine terminal responses and
nine mechanically valid cards**, without retries. The explicitly requested mean
retains a bounded slice; `bisector` now correctly declares its own factory interface
instead of mixing it with returned methods. But **33 of 36 facets abstain**, up
from 14 in the previous span run, and several supported narrow differences disappear.
All nine cards remain `context_required`; **no lead is qualified**.

The result is mixed, not a production-promotion decision. The three known facets
are supported by independent source/code reading, but fewer assertions are not
evidence of general accuracy. The new responses suggest excessive abstention when
the candidate has not already been established as implementing the requested
operation. That is a hypothesis about the wording/behavior of this run, not a
causal result or a measured false-negative rate.

## Supported declarations and unresolved usefulness

Case 8 input cites original body offsets **23000–23500**, which explicitly specify
`resolve(version, topic)` returning a hosted URI. The selected entrypoint is
`bisector(f)`, with an accessor/comparator argument. The declaration now correctly
names `selected_entrypoint`, not the parameters of a returned method. Output cites
**23500–24000**, which requires a well-formed URI, against the factory's visible
`return {left, center, right}`. This is an object of methods, not the numeric result
of invoking them. Both narrow declared-contract contrasts are supported, without
claiming that every possible integration is excluded.

Case 9 again cites **3500–4000**, explicitly listing `avg` in meaningful profiling.
The selected body sums/counts qualifying values, returns sum/count and implicitly
returns undefined when none qualify. Its three slice descriptions identify that
mean and leave ingest, other summaries and integration as remaining work.
This is a conceptual primitive, not verified numeric suitability, exception
behavior, actual adoption or an eligible contribution.

The prior irrelevant case-9 output citation is absent because output now abstains;
this does not demonstrate automatic citation-relevance verification. Similarly,
every runtime facet now abstains. Runtime/behavior overclaims are absent from
known assertions, but abstention itself proves no correct environment judgment.
The local timestamp and help-search analogy gain no slice, yet their unknown
outcomes must not be presented as correctly rejected false positives.

The main limit is **lost narrow negative triage**:

- Case 2 explicitly requests shell command strings with grep flags; the selected
  method is a filename-matching boolean predicate. Input/output/behavior contrasts
  do not require proof that this candidate already implements command generation.
  The new reasons use absence of such a relationship to avoid the comparison.
- Case 4 requests detecting mixed collections during dtype discovery. The shown
  declared `str | bytes` interface and scalar-encoding branch offer narrower
  contrasts, though they cannot prove runtime rejection of arbitrary collections:
  the body returns non-string values unchanged. Missing references leave overall
  context incomplete; they do not turn all unknowns into correct negatives.
- Case 8's outcome reason says a single requested behavior cannot be identified,
  despite the resolver contract identified by its own known input/output facets.
  The narrow resolver-versus-bisection distinction previously supported by the
  original source is lost, even while the factory interface description improves.

Other abstentions remain defensible: an unseen copy/follow/nest helper, unspecified
representation, missing acceptance/adoption details or only one codec half do not
establish full behavior. Do not force traversal/compression back to old conceptual
slice labels, or turn every unknown into a compulsory rejection.

The separate post-response review is an unpaid workspace-agent reading of the
retained sources and code, not a second paid grader, model self-certification or
statistical ground truth. All three known facets were inspected; no unsupported
known claim was identified in this run. With only three known assertions and 33
abstentions, that observation is not a precision/recall estimate or a general
quality improvement. Raw cards keep their semantic-verification flags false;
the independent review is never written back into them or application jobs.
