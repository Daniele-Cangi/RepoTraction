# Four-source repository-only Discover result

The initial frozen cohort completed all four Discover jobs once and produced
**zero source-grounded qualified external leads**. It retained 26 complete native
Luna responses, twelve selected targets, twelve persisted comparisons and one
charged candidate-local requirement-extraction failure. Conditional primitives
survived source reading, but none established the requested integration or a new
actionable connection. Some comparison labels still exceed the supplied evidence.

This is a usefulness assessment of the unchanged production contract-25 pipeline,
not a benchmark of accuracy or the effect of the separate experimental triage
prompt. The latter was not substituted. Four purposively selected repositories,
schema acceptance and a large number of unknowns do not establish improvement.

### Labels requiring qualification

For opengwas r0, the [supplied CLI body](https://github.com/mahmoud/glom/blob/fd70d3051a6a1bcb5152ec2d8e2cdc8e852f95e6/glom/cli.py#L52-L77)
calls `glom(target, spec)` and prints the result. It does not necessarily read
association/Analysis rows or built Store internals. Computing argv from accepted
bundle metadata can respect the requested seam. Calling every data transformation
incompatible broadens the actual ban. The specialized pure planner remains
undemonstrated, so removing this conflict does not produce a qualified lead.
Several inferred subdetails in r2/r4-r11 come from reported implementation progress;
they are not independent proof of fresh mandatory unmet work. The later author
report says the epic completed and PR121 opened; merge/current demand is unknown.

For httpr r2, [the wrapper](https://github.com/gruns/furl/blob/46d9ea79c98bb14b970a199fb924705d024f29ad/furl/furl.py#L327-L360)
selects schemes conditionally, delegates joining and may restore a scheme. Its
guards and supplied helpers establish a bounded control-flow description, not
that every absolute URL with a scheme is preserved as-is. For r3, lack of explicit
base/request path normalization is visible, and the request describes the desired
`/v1` policy. The actual standard-library delegate body and matching assertion
for this counterexample were not supplied. The definite delegated outcome is
therefore stronger than this source-only evidence. Rust/client integration and
the other eleven requirements remain unverified; no runtime execution was used
to repair that gap. These are source-grounding limits, not a claim that the
standard library behaves differently from its documented contract.

The dlt r4 contrast is narrower: [the visible two-line operation](https://github.com/psf/cachecontrol/blob/2627d9b267c2032dad2db1f639f3c59329008f1d/cachecontrol/serialize.py#L62-L63)
calls `msgpack.dumps`; the demand explicitly selects msgspec's encoder/decoder
integration. Rejecting this operation's direct adoption as-is is defensible. It
does not prove incorrect MessagePack bytes, a universal inability to adapt it or
successful target tests. The issue is 813 days old; open status is not evidence of
current adoption interest. Checking pretty-format support was correctly kept
distinct from requiring a new formatting implementation.

## Retrieval, omissions and decision

Generated queries were retained exactly: glom searched nested assignment,
nested-iterable flattening and command-line transformation; furl searched URL
splitting, ordered multivalue mapping and relative joining; CacheControl searched
HTTP response caching, HTTP lookup and MessagePack serialization; bidict searched
cached mapping hashes, item normalization and inverse iterators. Every source
selected three external projects through the existing balance/overlap/upstream-rank
policy, without manual substitution. All twelve exact selected issue URLs were
absent from the 941 protected historical files searched, a bounded local-history
finding rather than universal human novelty.

Retained pool metadata was inspected separately from selected-case judgments.
Pool metadata includes diverse bug reports, epics and learning notes; lexical
rank promoted the answered homework and incomplete tutorial into two paid slots.
This does not show that every remaining target is irrelevant. The summed 372
per-source pool entries are not a semantically labeled set, and the unselected
entries were not evaluated or added to the paid cohort. No recall, ranking-quality
or counterfactual winning lead is claimed.

Source acquisition scanned glom 24/54, furl 12/12, CacheControl 24/49 and bidict
24/42 eligible files. Static scans retained 100/100/87/100 capability declarations;
only 30 per source entered interpretation, omitting 70/70/57/70 respectively.
Capability packets also omitted 114/68/24/120 source fragments; interpreted
capability counts were 8/8/7/8. Furl's complete eligible-file sample does not make
its capped declarations/fragments complete evidence. Bounded search caps, omitted
cross-references, shortened roots and target samples remain material limitations.
For example, Agno supplied no target implementation, CellBender's posterior file
was omitted, and vLLM omitted 121 visible demand spans. Missing package references
do not prove novelty; an open issue does not prove current demand or adoption.

The outcome supports retaining useful conditional primitives and bounded
wrong-candidate contrasts, while reporting the overstrong labels, extraction
failure and evidence gaps separately. It establishes no actionable external lead
and no causal quality improvement. Candidate execution/isolation, UI/key-entry
work and production prompt/parser/scoring promotion remain deferred. This cohort
is closed; it authorizes no retry or additional paid investigation.
