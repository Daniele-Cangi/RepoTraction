## Useful mechanisms and defensible rejections

The strongest bounded example is `pRetry`/`makeRetriable` against the automatically
selected [fetchWithRetry request](https://github.com/vision72/eight-weeks-to-full-stack/issues/7).
The acquired implementation supplies retry scheduling and exponential backoff;
the target still needs a fetch-shaped adapter, failure policy for HTTP responses
and the requested mock-API test. A fulfilled fetch promise containing a non-OK
response must not be assumed to throw. The saved assessment is `needs_review`,
not an eligible lead or executed integration. Source review establishes a useful
partial mechanism, not adoption, novelty or whole-request fulfillment.

Several rejections are supported by operation/runtime distinctions:

- Mistune's Python parser is not a drop-in fix for the
  [Lemmy Node/markdown-it emphasis defect](https://github.com/LemmyNet/lemmy-ui/issues/4326).
- ANSI removal is not the Unicode/UTF-8 filename and IPC handling requested in
  [fetchflow](https://github.com/Mayanktaker/fetchflow/issues/6).
- Regex literal escaping is not the regex-pattern parsing and variable-resolution
  behavior requested in [Obsidian Clipper](https://github.com/obsidianmd/obsidian-clipper/issues/717).
  Preserving pattern syntax and escaping it into literal text are different operations.
- A generic retry loop does not implement the uncertain-side-effect bookkeeping
  requested in [OriginTrail](https://github.com/OriginTrail/dkg/issues/2892).

Other partials also need care. For the Python/PostgreSQL
[search-breaker request](https://github.com/michaeljboscia/search-breaker/issues/2),
ANSI stripping is a relevant primitive, not JSON validity, database integration or
a persistence fix. Strip decoded text before proper JSON encoding; the helper's
ESC/CSI fast path does not automatically clean escaped serialized JSON.

The two Async selections are explanatory articles:
[dependency injection](https://github.com/viphat/til/issues/271) and
[Promises](https://github.com/gnipbao/iblog/issues/10). The acquired discussion and
later label/assignment timeline contain no requested change or deliverable.
Luna returns source-cited `not_a_request` with complete supplied discussion, and
Missing Link retains each charged request outcome without fabricated requirements,
comparison or replacement. This is fresh verification of typed non-demand
