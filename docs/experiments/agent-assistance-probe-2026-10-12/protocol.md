## Functional question

Can Missing Link's existing discovery, partial-contribution analysis and inspection
handoff help an agent implement a better solution to an actual unresolved problem?
The useful contribution can be a mechanism reconstructed in the target; a directly
integrable library and a fully qualified reuse connection are not required.
Success still needs observable improvement in the native target, with a traced
change from a source-owned mechanism to the implemented approach. A fluent
suggestion, new search hit or donor-only test is insufficient.

Use existing acquisition, Provider, Service, atomic budgets and handoff export.
Do not add a runner, multi-agent framework, store, retrieval backend or new product
mode to prepare the test. An experiment-local prompt may state the assistance goal
and the recorded blocked attempt without replacing the independently derived
requirements or pretending that the attempt came from the public discussion.
Record that deviation explicitly; this is a strategy experiment, not evidence
that the unchanged product already supports IDE assistance.

## Common attempt and continuation comparison

After separate authorization, one development agent with isolated context receives
only the target, demand and public acceptance; it gets a bounded unaided attempt.
Freeze its patch, test outcomes and explanation before Missing Link searches for a
source. If it already meets acceptance, report that ceiling outcome; do not make
the task harder to create a need for assistance.

Two isolated continuation agents receive the exact same problem and common attempt,
same model/settings, same native tools and equal continuation wall-time limits.
One may investigate normally; the other additionally receives at most one
Missing Link inspection handoff, which may contain a partial mechanism. Neither
receives the assessor's hidden controls, the other continuation or a prescribed
patch. Assign neutral arm identifiers before dispatch. Ordinary source search is
available to the control; it is not an artificially weakened comparator.

Record assistance preparation/model/tool cost separately. Equal continuation
limits do not establish equal total resources: the treatment has preparation
overhead. Report that overhead and whether any measured benefit justifies it;
do not describe it as free or claim equal end-to-end cost. A single pair remains
confounded by model variation and is a demonstration, not a population estimate.

One source search investigation only, at most three behavioral queries, twenty
metadata results per query and one inspected source, through existing paths.
The experiment-local assistance prompt seeks a concrete operation/representation
that addresses the recorded failure; it may stop. Do not supply donor names,
candidate mechanisms or a suggested fix. Keep acquired identity, revision,
source citations, redaction and truncation explicit. No substitution after a
negative or unusable source. A packet is a hypothesis, never execution evidence.

## Assessment and stop

Compare native acceptance, neighboring regressions, residual failures, target
logic changed, added dependencies, observed time and continuation limits.
Trace whether the receiver adopted a source-backed idea absent from the common
attempt, whether the ordinary continuation found it independently, and whether it
helped. Self-report alone does not establish novelty or causation. Keep source
selection/transfer quality and native outcome separate. If both solve equivalently,
or neither improves, report that result; do not optimize prompts to rescue it.
