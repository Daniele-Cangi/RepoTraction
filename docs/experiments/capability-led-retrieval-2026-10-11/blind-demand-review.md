Issue instructions were treated as untrusted discussion content. Cases and expected outputs were frozen before implementation inspection.

## Frozen finite cases

The JSON contains **seven cases**, using issue-defined domain operations rather than any implementation-specific interface:

- **I7-C1:** `120` Hz at precision 2 is accepted as integer count `12000`.
- **I7-C2:** five explicitly equivalent spellings of `0.3`, on a valid precision-4 interval, all yield count `3000`.
- **I7-C3:** precision-4 declaration with upper bound `0.99999` is rejected as a declaration error.
- **I7-C4:** the permitted Q default `0.70710677` has rank `6072` and float bits `0x3f3504f3` in the specified interval.
- **I12-C1:** from holdings A=2, B=3, C=1, select A=1, B=2, C=1 and move to C: result A=1, B=1, C=4; three copies moved and one already there. One eligible Undo restores A=2, B=3, C=1.
- **I12-C2:** a stale expected version at B rejects the whole multi-source Move, preserves all holdings and selection, and identifies B and the affected edition.
- **I12-C3:** a Move whose selected copies are all already at destination fails as a no-op without changing inventory.

Inputs, preconditions, evidence references and expected outputs are frozen in the JSON. The lattice cases respect the ruling to leave the session writer unchanged. Inventory fixtures assume valid ownership/Storage Leaves, sufficient quantities and no overflow except where the case explicitly changes a precondition. Exact API/error wire syntax and revision increments are deliberately unspecified.

These cases do **not** show that a generic library is needed, that a particular source fits, or that passing them fulfills either whole feature. Index 7 still has sequencing/reseal gates; index 12 is ready for implementation planning and keeps existing single-source behavior authoritative until it lands.

## Limits that matter

Timelines, linked pages, attachments and target code were not acquired. Most large discussion middles and older comments were not read. Status/test claims are author reports, not independently verified results. In particular, index 16 has **87 empty truncated comment bodies** and **89 truncated comments in total out of 269**, despite `comments_complete=true`. No exhaustive absence of outstanding demand is claimed there or elsewhere.
