## One-shot execution and preservation

The owned driver checks frozen source, configuration, inputs, requests, history
and budget before taking the existing worker lease. An exclusively created start
marker prevents replay. The CLI identity must freshly verify as `Daniele-Cangi`
before each request; the existing bounded identity cache applies only inside that
request. Existing production jobs, including paused work, are not resumed.

The public executor `scripts/missing_link_triage_branch_execution.py` uses the
unchanged experimental receipt reader and Budget contract. Full decoded terminal
JSON is saved privately before stream closure, output parsing or acceptance,
including extra event fields, metadata, incomplete details and refusals. This is
terminal JSON, not original wire whitespace or preceding SSE deltas. Missing,
malformed or status-inconsistent terminal events are never certified or invented.
Private receipts are not imported into production jobs, logs, reports or the UI.

Transport, account, allowance, missing-terminal, incomplete/refused output,
provider-schema, receipt-storage and stream-close errors stop further calls.
Only local normalization/provenance failure after a completed provider response is
candidate-local: preserve the parsed card and validation error, then attempt the
next case once. No response is repaired or retried. Unknown native usage remains
unknown and its conservative reservation remains charged.

Only owned in-flight job receipts may be updated. Terminal receipts, case results,
start marker and diagnostics use exclusive creation. After lease release, integrity
permits at most nine uniquely owned exact reservation rows and their increment of
the original allowance. All 498 earlier reservation rows, other allowances, ten
non-accounting tables and **580 prior artifact hashes** must remain identical.
Historical cards and reports are never overwritten or regraded.
