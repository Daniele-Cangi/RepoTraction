mechanically valid cards**, without retries. Compared with the preceding explicit

## Supported comparisons and semantic problems

The independent review inspects every known facet against its exact cited chunk
and the selected body. It does not write semantic-verification flags back into the
cards; those flags remain false.

- **NumPy input:** original `q0` offsets 500–1000 describe mixture detection within
  and between concatenate inputs. The candidate declares one `s: str | bytes`
  argument. Luna explicitly calls this a declared interface contrast and disclaims
  runtime rejection. That bounded statement is supported.
- **Timestamp outcome:** `q0` 1500–2000 requires `ots stamp` on the tag commit hash
  and a public `.ots` proof. The visible candidate appends an encoded
  `get_timestamp()` value and a `get_signature()` result to bytes. The narrow
  entrypoint-mechanism contrast is supported, but it proves neither a local-clock
  implementation nor that unseen helpers cannot access an external service. It
  must not be promoted to a complete workflow rejection or an external-anchor
  slice.
- **Help resolver input/output/outcome:** `q0` 23000–23500 specifies
  `resolve(String version, String topic)`, and 23500–24000 requires a mapped-topic
  URI. The candidate takes `f`, constructs binary-search methods and returns
  `{left, center, right}`. All three narrow comparisons name the factory layer
  correctly; none uses returned-method parameters/results as the factory's own.
- **Mean slice:** `q0` 3500–4000 explicitly lists `avg`. The candidate counts/sums
  qualifying values and returns `sum / count` when count is nonzero. Luna limits
  its contribution to this average, leaving the other profiling statistics and
  integration unestablished. Numeric suitability, infinities, coercion policy,
  accessor exceptions and real adoption remain untested.

Two known NumPy facets need qualification. The body is structurally:

```python
if isinstance(s, str):
    s = s.encode(encoding, errors)
return s
```

It encodes strings, but returns non-string inputs unchanged. The model's output
reason nevertheless says the body returns a bytes value; its outcome declaration
says the entrypoint returns bytes rather than an object array. Those general
return claims are not established by the body. An object array supplied as `s`
would take the unchanged-return branch; this is direct source reading, not an
executed test. A declared `-> bytes` contract can be contrasted, but cannot silently
replace the original model's observed-return claim. The single-string encoding
branch also does not itself prove a universal mixed-collection behavior difference.
The raw `different` relations remain preserved and are not certified as fully
supported by the review.

The other unresolved problem is case 2. Its acquired discussion explicitly
requests generated commands with `grep -P`, context flags and multiple `-e`
patterns. The candidate returns a filename-matching boolean. Luna itself describes
both contrasts, then abstains because their outputs are not established as belonging
to the same requested operation. The reviewed prompt explicitly removes the need
to prove that the candidate already implements that operation. This remains lost
useful negative triage, not a correctly rejected false positive. It does not justify
whole-project runtime exclusion or force every unrelated primitive into a known
comparison.

Genuine delegate gaps in atomic copy, traversal and `group` remain unknown, and
the codec half does not establish an entire reversible research system. Retaining
these abstentions matters as much as recovering supported local contrasts. This
single run does not establish the cause of either improvement or overabstention;
no repeated-run or statistical accuracy claim is made.
