## Evidence and persistence

Target acquisition uses the existing public-only, tree/path, credential and
symlink filters. It attempts at most two root manifests and two cited source
files. Discussion paths and same-target GitHub blob links identify files in the
**current pinned default-branch tree**, not historical target code from arbitrary
linked revisions. Excerpts keep their original prefix/line positions, capped at
32,768 characters per file. Target evidence is labelled `target:PATH`, not
`file:PATH`, so target implementation cannot masquerade as a source contribution.
Discussion-specific context fingerprints prevent reuse of the wrong file sample.

Python dependency metadata is parsed statically; no setup/build/import code from
the acquired repository runs. Missing parsers, malformed dependency metadata and
truncated manifests stay explicit review blockers. On Python 3.10, optional
Tomli enables TOML review; without it, core operation continues but TOML review
cannot be treated as complete.

AI attempts have stable `job_id:call_number` identifiers shared by their trace,
saved schema-valid output and candidate failure. Quote diagnostics expose only
kind, normalized requirement ID, a supplied source ID (or null), character count
and SHA-256. No quote/prompt/key is echoed into public job errors. Stored attempts
retain credential redaction and are excluded from polling state. Usage remains
reserved even when semantic validation rejects an attempt.

Historic contract-7/8 matches are retained unchanged and marked stale by contract
9. No source review, paid reanalysis, feedback mutation or target publication
happens automatically. The original cohort and its charged allowance are not
rewritten to improve the apparent outcome.
